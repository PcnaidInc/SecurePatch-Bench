# Roadmap

## v0.1 - Oracle-validation pilot

- [x] Nine synthetic TypeScript scenarios
- [x] Three categories: authorization, tenant isolation, webhooks
- [x] Vulnerable, naive, and reference variants
- [x] Paired functional and security oracles
- [x] Machine-readable manifests
- [x] CLI, CI, JSON output, and Markdown report
- [x] Technical report describing design and pilot results

## v0.2 - Agent adapter and repeated-run protocol

- [ ] Standard patch/candidate adapter
- [ ] Repetition, seed, model, prompt, and tool metadata
- [ ] Cost, latency, and token accounting
- [ ] Patch-size and touched-file measurements
- [ ] Failure taxonomy
- [ ] Optional container isolation

## v0.3 - Expanded scenario coverage

- [ ] 30 scenarios across six synthetic SaaS applications
- [ ] Additional cache, queue, export, storage, and webhook paths
- [ ] Cross-file and multi-service repairs
- [ ] Independent application-security review
- [ ] Contributor scenario-validation toolkit

## v1.0 - Stable public benchmark

- [ ] Frozen evaluation split and versioned test contract
- [ ] External replication
- [ ] Public benchmark card and model-result format
- [ ] Release DOI or archival identifier
- [ ] Documented governance for hidden tests and result submissions
