# Security Policy

## Scope

This repository contains synthetic defensive benchmark scenarios. It should not contain production credentials, personal data, customer code, or active third-party target information.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could affect users or expose sensitive information. Email:

- `support@pcnaid.com`

Include:

- affected version and file;
- impact and reproducible local steps;
- whether the issue exposes a real external system;
- proposed embargo needs;
- a safe contact method.

Pcnaid will acknowledge a good-faith report when operationally possible, assess severity, coordinate remediation, and provide publication guidance. Do not access data beyond what is necessary to demonstrate the issue, degrade services, or test systems outside your authorization.

## Supported versions

Security fixes are applied to the latest release and default branch. Earlier versions may receive fixes when practical.

## Safe harbor intent

Pcnaid supports good-faith research performed against this repository or systems for which the researcher has explicit authorization, provided the research avoids privacy violations, data destruction, persistence, lateral movement, social engineering, and service disruption.
